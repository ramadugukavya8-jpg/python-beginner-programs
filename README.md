# Python Beginner Programs

Beginner-level Python programming exercises for my coding and skill development practice.

## Programs

1. **Calculator** - Performs basic arithmetic calculations.
2. **Even or Odd** - Checks whether a number is even or odd.
3. **Factorial** - Calculates the factorial of a number.
4. **Largest Number** - Finds the largest among three numbers.
5. **Multiplication Table** - Prints the multiplication table of a number.
6. **Prime Number** - Checks whether a number is prime.

## Language

Python

These programs are part of my beginner-level coding practice and skill development.
